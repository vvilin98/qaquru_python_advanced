* [Python 3.12]()

---

### 📁 Структура проекта

```
.
├── app                                     # Микросервис
    ├── users_service                       # Корень сервиса для работы с пользователями
        ├── main.py                         # API для работы с пользователями 
        └── models.py                       # Структура данных для работы с пользователями на основе Pydantic
├── data
    └── db.py                               # Импровезированная БД
├── test
    └── test_microcervice.py                # Тесты на микросервис
├── tests_reqres
    └── test_reqres.py                      # Тесты на https://reqres.in
├── README.txt                              # Документация проекта
└── requirements                            # Зависимости проекта
```

---
### 🚀 Как запустить

#### 1. Клонировать репозиторий

```bash
git clone https://github.com/vvilin98/qaquru_python_advanced.git
```

#### 2. Установить зависимости

```bash
pip install -r requirements.txt
```

#### 3. Запустить FastAPI-сервер

```bash
uvicorn app.users_service.main:app --host 127.0.0.1 --port 8003 --reload

```

#### 4. Запустить тесты

```bash
pytest -v tests/ 
```
